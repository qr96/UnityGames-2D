# Grab Hero (GrabProto) — 게임 디자인 문서

> **버전**: 프로토타입 v0.9 (구현 반영본) · **화면**: 3:4 세로 (기준 1080×1440)
> **표기 규칙**: `※임시` = 플레이테스트 후 조정 예정 수치 · `[미정]` = 기획 미확정 항목
> 이 문서는 구현 상태를 따라가는 살아있는 문서다 — 명세 변경 시 함께 갱신한다.

---

## 1. 컨셉

**영웅을 손으로 "잡아서" 싸우는 로그라이트 던전 크롤러.**

- 전투는 자동으로 흐르지만, 플레이어는 영웅을 집어 옮기는 것으로 개입한다.
  잡는 순간이 곧 판단의 순간 — **잡는 동안 시간이 천천히 흐른다** (실험 기능).
- 던전은 깊이 내려갈수록 강해지고(적·보상 모두), 플레이어는 매 순간
  **"더 털 것인가 / 안전하게 나갈 것인가 / 더 내려갈 것인가"**를 선택한다.
- 영웅과 장비는 영구 자산이다. 단, 원정에서 죽은 영웅은 장착품과 함께 영원히 사라진다.

## 2. 코어 루프

```
로비 ──출정(1~5명 + 출발 층 선택)──▶ 던전
 ▲                                    │
 │   영입(골드) · 편성 · 보관소          │  층 탐색 → 방 클리어 → 인접 공개
 │                                    │  계단 확보 → [더 탐색 / 귀환 / 하강]
 └──── 귀환: 전리품·골드 확정 ◀─────────┘  전멸: 이번 원정 획득물 + 출전 영웅 상실
                                          최심부(40F) 보스 격파 = 원정 클리어
```

- **귀환**은 계단 확보 후, 또는 외부 진입 포인트 개통 후 **층 어디서든** 가능 (백트래킹 없음).
- **하강**은 계단 확보 시에만. 하강할 층은 그 시점에 새로 생성된다.
- 원정 종료(귀환/전멸) 시 영입 상점 후보가 전체 갱신된다.

## 3. 영웅

### 3.1 스탯 (영웅 스펙 v2)

- 영웅마다 생성 시 스탯을 **굴림** — 같은 이름이라도 능력치가 다르다.
- 레벨 1~10, 스탯은 Lv1 굴림값 → Lv10 굴림값 선형 성장.

| 스탯 | Lv1 굴림 범위 | Lv10 굴림 범위 | 비고 |
|---|---|---|---|
| 최대 HP | 80~120 | 140~220 | |
| 공격력 | 8~12 | 14~22 | |
| 치명타 확률 | 3~7% | (성장 없음) | |
| 치명타 피해 | 140~160% | (성장 없음) | |

- 경험치/레벨업 규칙 **[미정]** — 레벨 필드와 보간만 구현됨.

### 3.2 시작 영웅 (고정 3명)

| 영웅 | HP | 공격 | 치확/치피 | 액티브 | 특성 | 무기 |
|---|---|---|---|---|---|---|
| 브란 | 115 / 175 | 9 / 17 | 4% / 150% | 전투 함성 | 끈질김 | 검 |
| 리나 | 90 / 160 | 12 / 20 | 7% / 155% | 저격 | 처형인 | 활 |
| 오웬 | 100 / 185 | 10 / 18 | 5% / 145% | 응급 치료 | 전우애 | 마법 도구 |

### 3.3 슬롯과 무기

- 슬롯: **무기 1 + 자유 장비 3** (자유 슬롯은 종류 제한·중복 제한 없음).
- 무기 미장착 시 **기본 공격 불가** (내려놓기 액티브는 조건 충족 시 사용 가능).
- 무기 프로필 고정 (장비 명세 v1.2 §12):

| 무기 | 사거리 | 공격 주기 | 방식 |
|---|---|---|---|
| 단검 | 1.2 | 0.65초 | 근접 단일 |
| 검 | 1.5 | 1.0초 | 근접 단일 |
| 대검 | 1.8 | 1.5초 | 전방 소범위 (반경 1.0 ※임시) |
| 활 | 6.0 | 1.2초 | 원거리 투사체 |
| 마법 도구 | 4.5 | 1.4초 | 원거리 투사체 |

- 모든 무기의 깡스탯은 공격력. 사거리/주기의 원천은 무기다 (영웅 고유치 아님).
- 생성 시 기본 무기 1회 지급 ※임시 (무기 획득 흐름은 드랍이 담당).

### 3.4 액티브 스킬 (10종 — 생성 시 1개 고정, 교체·성장 없음)

| 스킬 | 발동 | 무기 조건 | 효과 요약 |
|---|---|---|---|
| 강타 | 자동 | 근접 | 단일 큰 피해 |
| 휩쓸기 | 자동 | 근접 | 전방 부채꼴 |
| 저격 | 자동 | 활 | 원거리 관통탄 |
| 화염구 | 자동 | 마법 도구 | 착탄 폭발 (본체 처치 시에도 폭발) |
| 처형 | 자동 | 근접 | 낮은 HP 대상 강타 |
| 회복 | 자동 | 없음 | 아군 회복 |
| 전투 함성 | 내려놓기 | 없음 | 주변 아군 공격 버프 |
| 충격파 | 내려놓기 | 없음 | 주변 피해+넉백 |
| 보호막 | 내려놓기 | 없음 | 아군 보호막 |
| 응급 치료 | 내려놓기 | 없음 | 아군 즉시 회복 |

- **내려놓기 발동**: 쿨 완료 + 조건 충족 상태에서 영웅을 내려놓는 순간 발동. 아니면 그냥 재배치.
- 수치 전부 ※임시.

### 3.5 특성 (12종 — 생성 시 1개 고정)

전투 중 조건을 상시 판정하는 패시브. 수치 전부 ※임시.

| 특성 | 조건 → 효과 |
|---|---|
| 궁지의 투사 | HP ≤35% → 공격 +30% |
| 끈질김 | HP ≤35% → 받는 피해 -30% |
| 처형인 | 대상 HP ≤35% → 그 대상 피해 +30% |
| 결투가 | 주변 3 내 적 1명뿐 → 공격 +25% |
| 난전광 | 주변 3 내 적 3명+ → 공격 +25% |
| 고독한 늑대 | 주변 4 내 아군 없음 → 공격 +30% |
| 전우애 | 주변 4 내 아군 있음 → 받는 피해 -20% |
| 수호자 | 주변 4 내 HP 35%↓ 아군 → 받는 피해 -30% |
| 복수심 | 이번 전투 아군 사망 → 공격 +30% (전투 동안) |
| 선봉장 | 전투 시작 8초간 공격 +30% |
| 생존본능 | HP ≤30% 도달 → 전투당 1회 최대 HP 20% 회복 |
| 무모함 | 상시 주는 피해 +25% / 받는 피해 +25% |

## 4. 잡기 (핵심 조작)

- 잡힌 영웅: 이동/공격 중지, 손가락 추적, 버둥거림, **피격은 가능**. 놓으면 착지 딜레이 후 복귀.
- 잡히면 채널링(조준/연사) 취소.
- **잡기 슬로우 모션** (실험): 교전 중 잡는 동안 시간 배율 0.35 ※임시, 전환 0.12초.
  잡힌 영웅의 추적/버둥은 원래 속도 — 세상만 느려진다. 준비/탐험 중에는 미적용.

## 5. 던전

### 5.1 구조

- 단일 지역 = 1F~**최심부 40F** (`maxFloor` 데이터화). 최심부에 보스.
- 각 층 맵은 **진입(하강) 시점에** 랜덤 생성. 같은 층 재진입도 새 맵.
- RewardLevel = 현재 층 번호. 깊을수록 적·장비 모두 상승.

### 5.2 방 5종

| 방 | 전투 | 역할 |
|---|---|---|
| 일반 전투방 | O | 탐험 기본 비용, 기본 장비 획득처 |
| 엘리트 전투방 | O (강화) | 고위험·고보상 — 특별 장비 확률 높음 |
| 보물방 | X | 다량 장비 (막다른 가지 배치) |
| 계단방 | X | 확보 시 귀환/하강 개방 |
| 외부 진입 포인트 | X | 11/21/31F ※임시 — 도달 즉시 영구 개통, 이후 출발 지점 |

### 5.3 생성 규칙 (방 생성 명세 v1.0 — 파라미터 전부 데이터화)

- 격자 위 랜덤 **트리** + 조건부 재합류(트리 거리 4+ 인접 방, 확률 35%). 무의미한 루프 금지.
- 방 수 10~14. 계단까지 전투 거리 2~6 (3~4 선호). 검증된 분포: 평균 3.18회.
- **엘리트는 계단 필수 경로에 배치 금지** — 선택 가지에만.
- 보물은 경로 밖 막다른 가지 우선, 단 "막다른 길 = 반드시 보물" 공식 금지.
- 첫 분기는 전투 2회 내. 품질 검증 8항목 미달 시 폐기·재생성 (최대 30회).
- 계단 확보 후에도 경로 밖 유혹 요소(엘리트/보물) 최소 1개가 남도록 보장.

### 5.4 정보 공개·클리어

- 미공개(Hidden) 방은 **존재/연결/종류 전부 은닉 + 이동 불가**.
- 방 클리어(전투) 또는 방문(비전투) 시 인접 Hidden 방이 공개(Revealed — 종류까지).
- 클리어한 방은 원정 동안 안전 — 재전투 없음 (특수 기믹만 예외 가능, 사전 인지 필수).
- 이동은 양방향. 보물은 방당 1회 회수.

### 5.5 계단·귀환·하강

- 계단방 **도달 = 확보(Secured)** — 이후 층 어디서든 [귀환]/[하강] (백트래킹 추상화).
- 진입 포인트 도달 = 영구 개통 + 그 원정 귀환 가능 (하강은 계단 전용).
- 귀환 시 전리품·골드 확정. 층 사이 자동 회복·캠프 없음.

### 5.6 최심부 보스

- 40F는 계단 없음 — "최심부" 방(강화 엘리트: 엘리트 배수 × 랜드마크 배수 중첩). 승리 = 원정 클리어.
- **보스 처치 보상 [미정]** — 별도 보상 항목으로 유보, 임의 규칙 적용 금지.

## 6. 전투

- 자동 전투 + 잡기 개입. AI는 최근접 대상.
- 적 스폰: 총 마릿수를 배치(1~2마리씩, 간격 2.5초 ※임시)로 나눠 투입. 스폰 예고 0.5초.
- 포션: 전투당 3개 ※임시.
- 치명타: 피해 증감 적용 후 판정 (기본 공격 기준 — 스킬 치명타 [미정]).

### 6.1 적 스케일링 (층 기반 — "깊이 = 난이도")

| 항목 | 값 (※임시) |
|---|---|
| 1층 일반 적 | HP 35 / 공격 5 / 5마리 |
| 층당 성장 | 스탯 +15%, 마릿수 +0.5 (상한 16) |
| 엘리트 | 스탯 ×1.5, +2마리 |
| 최심부 보스 | 엘리트 ×1.5 × 랜드마크 ×1.6 (≈ 일반의 2.4배) |

참고 곡선: 11F 적 HP 88/공 12.5 · 20F 135/19 · 40F 240/34 · 보스 HP ≈575.

### 6.2 피해 공식 (장비 명세 v1.2 §6~9 — 순서 고정)

```
공격력 계산: (기본 + flat 합) × (1 + %합)
피해 산출:  공격력 → 스킬/공격 계수 → 주는 피해 증감(합연산) → 치명타
피해 수용:  받는 피해 증가(곱) → TotalDR 적용 → 보호막 흡수 → HP
```

- **TotalDR**: 장비 옵션 + 고유효과(DROP_GUARD) + 특성 + 버프의 모든 "받는 피해 감소"를
  **단일 합산 → 75% 상한** (무적 방지). 받는 피해 "증가"(무모함 등)는 별도 곱.
- 보호막은 감소 계산 **이후**의 피해를 흡수.
- 상한: CDR 30%, 공격 주기 감소 30%, DR 75%. RANGE 상한 없음.

## 7. 장비

### 7.1 구조

- 장비는 드랍 시 **절차 생성**되는 개별 인스턴스 (고정 장비 없음, 등급 없음).
- **일반**: 깡스탯 1 + 공통 옵션 1. **특별(★)**: + 고유효과 1.
- 전투 타입은 3종뿐: 무기 / POWER_GEAR(공격력) / VITAL_GEAR(최대 HP). 외형·이름은 자유.
- 특별 장비라도 같은 RL의 일반보다 깡스탯이 높지 않다.

### 7.2 드랍 (획득처가 개수·특별 확률을, 층이 깡스탯을 결정)

| 획득처 | 드랍 수 | 특별 확률 (※임시) |
|---|---|---|
| 일반 전투 | 1 | 1% |
| 엘리트 | 2 | 8% |
| 보물방 | 3 | 3% |

- EquipmentType 각 1/3, 무기면 WeaponType 각 1/5.
- 깡스탯 RL 선형 보간 (Rmax 40, 반올림): 공격 `1~3 → 9~13`, HP `15~30 → 90~130`.
- 옵션·고유효과 수치는 RL과 무관 (깊이로 강해지지 않음).

### 7.3 공통 옵션 8종 (장비당 정확히 1개, 동일 가중치, 합연산 중첩)

| 옵션 | 범위 |
|---|---|
| 공격력 % | +6~12% |
| 최대 HP % | +8~15% |
| 치명타 확률 | +2~4%p |
| 치명타 피해 | +10~20%p |
| 받는 피해 감소 | +4~8% |
| 쿨다운 감소 | 5~10% |
| 기본공격 사거리 | +8~15% |
| 기본공격 주기 감소 | 5~10% |

### 7.4 고유 효과 8종 (특별 장비 — 동일 효과 중첩 시 효과량 합산)

| 효과 | 조건 → 효과 |
|---|---|
| 최후의 저항 | HP ≤20% → 주는 피해 +30% |
| 건강한 격노 | HP ≥80% → 주는 피해 +20% |
| 처형 | 대상 HP ≤30% → 그 대상 피해 +25% |
| 피의 갈증 | 적 처치 → 최대 HP 5% 회복 |
| 낙하의 격노 | 내려놓음 → 3초 주는 피해 +25% (재발동 시 3초 갱신, 누적 없음) |
| 낙하의 수호 | 내려놓음 → 3초 받는 피해 감소 25% (TotalDR 합산) |
| 연계 일격 | 액티브 발동 → 다음 기본공격 +50% (충전-소비, 재충전) |
| 비상 보호막 | HP 최초 25%↓ 진입 → 최대 HP 20% 보호막, 전투당 1회 (지속 15초 ※임시) |

### 7.5 영속 (장비는 소멸하지 않는다)

- 미장착 장비 = **보관소(Armory)**. 장착 장비 = 영웅 소유 (영웅과 운명 공유).
- 귀환/클리어: 자동 영속 (옮기는 절차 없음). 전투 중 장비 변경 불가.
- **전멸**: 이번 원정 획득분만 소멸. **사망**: 장착품이 영웅과 함께 소멸.
- 해고: 장비/무기는 보관소 회수.

## 8. 메타 (로비)

### 8.1 로스터·영입

- 로스터 최대 **8명**, 출전 **1~5명** 자유 선택. 원정 중 파티 고정.
- 영입 상점: 후보 **3칸**, 정보 **전부 공개** (스탯/최대치/액티브/특성).
  가격 100골드 ※임시. **원정 종료 시 전체 갱신, 수동 리롤 없음.**
- 해고: 골드 환급 없음. 사망: 영구 (로스터에서 제거).
- 전멸로 로스터가 비면 시작 3명 재지급 ※임시 (소프트락 방지).

### 8.2 골드 (임시 경제)

- 시작 300 ※임시. 전투 승리 시 적립: 일반 10 / 엘리트 20 ※임시.
- **귀환/클리어 시 입금, 전멸 시 적립분 소멸** (전리품과 동일 규칙).
- 보물방·개통·보스 골드 보상 없음 (필요 시 확장 자리만 있음).

### 8.3 출발 지점

- 기본 지하 1층. 개통한 진입 포인트 층(11/21/31)을 출정 시 선택 가능.
- 진입 층 출발 시 적 스케일·RewardLevel 모두 그 층 기준.

## 9. UI/UX

- **3:4 세로 (1080×1440), 폭 기준 스케일.**
- 정보 표기 원칙 (가독성 개편에서 확립):
  - **라벨/보조는 작은 회색, 값은 크고 흰색** — 문장이 아니라 스캔 가능한 구조로.
  - 스탯은 고정 x좌표 열 배치 (폰트 무관 정렬). 특성 이름은 금색 강조.
  - 최대 레벨(`Lv.n / 10`)은 영웅 관리 상세에서만 노출 (영입 카드는 Lv만).
- 로비: 하단 바 4버튼(보관소/영입/영웅 관리/출정) + 패널(영입 카드 3행 / 관리 목록+상세 /
  보관소 스크롤 / 출정 로스터+출발 층).
- 게임: 상단 라벨(2줄) + 좌상단 지도. 준비 = 상단 장비 패널 + 하단 전투 시작/인벤토리.
  탐험 = 방향 슬롯(이름+미리보기) + 계단 확보 시 귀환/하강 패널 상시.
- 장비 상세는 이름 문자열 요약(`★대검 (공격+7, 치피+14) [최후의 저항]`) — 전용 툴팁 [미정].

## 11. 기술 부록 (요약)

- **의존 규칙**: Data(무참조) → Run → Core/Units, UI/World는 이벤트 구독, Bootstrap이 조립.
- **데이터화 위치**: 맵 생성 = `MapGenerator.Config` · 적/보상 = `RunConfig` ·
  장비 생성 = `EquipmentGenerator.Config` · 특성 = `TraitCatalog` · 슬로우 = `GrabSlowMotion`.
- **에디터 워크플로**: 씬은 [로비 씬 구성]/[게임 UI 생성] 풀빌드 1회, 기능 추가분은
  [UI 패치] (멱등), 부분 교체는 [재생성/...]. 데이터 에셋은 [게임 데이터 에셋 생성].
- 인메모리 메타(재실행 시 초기화): 로스터/보관소/골드/개통 층/후보 — 저장 시스템 대기.
